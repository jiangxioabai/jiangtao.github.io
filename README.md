# 姜滔 / Tao Jiang

个人学术主页。部署地址：https://jiangxioabai.github.io/jiangtao.github.io/

## 发布

1. 在 jiangxioabai 账号下使用公开仓库 jiangtao.github.io。
2. 将本目录的内容直接放入仓库根目录；index.html 应在根目录。
3. 仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。

## 修改

- content.js：中英文个人资料、研究方向、论文与项目。
- index.html：页面结构。
- style.css、backgrounds.css、profile.css、layout.css：样式。
- assets/tao-jiang.jpg：个人照片。
- assets/tao-jiang-cv.pdf：可下载简历。
- compare.html：保留的风格比较页。

无需构建工具。运行 python -m http.server 8765 后本地预览。

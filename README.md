# 姜滔 / Tao Jiang

中英双语学术个人主页。

网站：https://jiangxioabai.github.io/jiangtao.github.io/

## 内容

- content.js：个人介绍、研究方向、论文与项目。
- index.html：页面结构。
- main.js：语言切换与内容渲染。
- style.css、backgrounds.css、profile.css、layout.css：页面样式。
- assets/lilies.jpg：睡莲横幅。
- assets/tao-jiang.jpg：个人照片。
- assets/tao-jiang-cv.pdf：简历。

网站仅使用睡莲背景。无需构建；GitHub Pages 从 main 分支根目录发布。

本地预览：python -m http.server 8765
